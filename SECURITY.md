# Security Policy

## Supported versions

The latest release of the app is supported with security fixes.

## Reporting a vulnerability

Please report security issues **privately**:

- Email: contact@streamline-solutions.ch
- Or open a private report:
  https://github.com/StreamLINE-Solutions/nextcloud-flowline/security/advisories/new

Do not use public issues for security reports. We will acknowledge receipt
within a few days, keep you informed about the progress and credit you in the
release notes unless you prefer to stay anonymous.
